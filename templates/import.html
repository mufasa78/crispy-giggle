Import Options
Enter a valid Shopee product URL in the format: https://shopee.tw/xxx-i.{shop_id}.{item_id}
CSV format: column 1 = index, column 2 = Shopee product URL
Instructions
Option 1: Single URL Import
  1. Enter a Shopee product URL in the "Single URL" tab
  2. The system will extract the shop_id and item_id from the URL
  3. A job will be created to fetch data for this product
  4. View the results in your dashboard once processing is complete
Option 2: Batch Import with CSV
  1. Prepare a CSV file with Shopee product URLs (use the provided test_items_ids file format)
  2. Upload the file using the "CSV Upload" tab
  3. The system will extract the shop_id and item_id from each URL
  4. A job will be created to fetch data for all products
  5. View the results in your dashboard once processing is complete
URL must follow this format: https://shopee.tw/product-name-i.104581011.24901963692
The important part is the -i.{shop_id}.{item_id} pattern at the end of the URL.
