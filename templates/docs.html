Introduction

This API provides access to product data from Shopee Taiwan. It allows you to create asynchronous jobs to fetch data for multiple product IDs and retrieve the results when processing is complete.

The base URL for all endpoints is: /api/v1

Authentication

All API requests require authentication using an API key. Include your API key in the Authorization header of each request:

Authorization: Bearer YOUR_API_KEY

If you don't have an API key, please contact the administrator to obtain one.

Create Job

POST /api/v1/job/create

Creates a new asynchronous job to fetch data for multiple product IDs.

Request Headers:
Header Required Description
Content-Type Yes application/json
Authorization Yes Bearer YOUR_API_KEY
Request Body:
{
  "job_id": "34c4e7623450",  // Optional
  "deals": [
    {
      "deal_id": "1988776.7648272833",
      "step_id": "123546",
      "priority": 2
    },
    {
      "deal_id": "1877554.6761418533",
      "step_id": "123893",
      "priority": 1
    }
  ]
}
Parameters:
Parameter Type Required Description
job_id string No A custom job ID from your side. If not provided, a UUID will be generated.
deals array Yes An array of deal objects to process.
deals[].deal_id string Yes The product deal ID in the format "{shop_id}.{item_id}".
deals[].step_id string Yes The step ID for this deal.
deals[].priority integer Yes The priority for processing this deal (lower values = higher priority).
Response (200 OK):
{
  "success": true,
  "code": null,
  "message": null,
  "data": {
    "vendor_job_id": "1234abcd"
  }
}

Get Job Results

GET /api/v1/job/result/{vendor_job_id}

Retrieves the results of a previously created job.

Request Headers:
Header Required Description
Authorization Yes Bearer YOUR_API_KEY
URL Parameters:
Parameter Type Required Description
vendor_job_id string Yes The vendor job ID returned from the create job endpoint.
Response (200 OK):
{
  "success": true,
  "code": null,
  "message": null,
  "data": {
    "vendor_job_id": "1234abcd",
    "status": "success",
    "deals": [
      {
        "deal_id": "1988776.7648272833",
        "step_id": "123546",
        "priority": 2,
        "status": 2,  // 1-processing, 2-success, 3-failure
        "data": {
          // Raw product JSON data from Shopee
          "code": null,
          "data": {
            "item": {
              "item_id": 7648272833,
              "shop_id": 1988776,
              // ... more product data
            }
          },
          // ... more data
        }
      },
      // ... more deals
    ]
  }
}

Error Handling

All API errors follow a consistent format:

{
  "success": false,
  "code": "error_code",
  "message": "Human-readable error message"
}
Common Error Codes:
Code HTTP Status Description
unauthorized 401 Invalid or missing API key.
invalid_request 400 The request body is invalid or missing required fields.
job_not_found 404 The requested job was not found.
job_already_exists 409 A job with the provided job_id already exists.
server_error 500 An unexpected server error occurred.
